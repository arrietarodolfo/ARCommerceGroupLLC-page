# AR Commerce Group LLC — Corporate Website

Official corporate and informational website for **AR Commerce Group LLC**, based in Saint Johns, Florida. Specialized in multichannel e-commerce and wholesale retail distribution across Amazon, eBay, Walmart, and curated digital storefronts like ARCreativeGroup90.

## 🚀 Live Demo & Deployment
This project is built as a production-ready, standalone single-file HTML5 architecture and can be deployed directly to **GitHub Pages**, Netlify, Vercel, or any static hosting service.

### Deploying to GitHub Pages for Free:
1. Push this repository to your GitHub account.
2. In your GitHub repository, go to **Settings** > **Pages**.
3. Under **Build and deployment** > **Branch**, select `main` and folder `/ (root)`.
4. Click **Save**. Your website will be live in 1-2 minutes at:
   `https://<your-github-username>.github.io/<repository-name>/`

## 🛠️ Tech Stack & Architecture
- **Semantic HTML5 & Accessible Landmarks:** Full WCAG AA conformance with accessible contrast, visible keyboard focus indicators, skip-to-content links, and ARIA attributes.
- **Modern Tailwind CSS (CDN):** Custom institutional color theme (`#1A56DB`, `#0F172A`, `#F8FAFC`, `#334155`), fluid typography, and generous airy whitespace.
- **Vanilla JavaScript:** Zero external JS dependencies. Features include:
  - Sticky glassmorphism header scroll detection
  - Mobile responsive drawer navigation
  - Scroll-reveal animations using `IntersectionObserver` (respecting `prefers-reduced-motion`)
  - Client-side form validation with XSS sanitization and anti-spam honeypot
  - Smooth Back-to-Top scroll controller
- **Search Engine Optimization (SEO):**
  - Rich Open Graph & Twitter Cards metadata
  - Single `<h1>` hierarchy with structured `<h2>` and `<h3>` tags
  - Embedded Schema.org JSON-LD structured data for `Organization` and `LocalBusiness`
- **Security Best Practices:**
  - Content Security Policy (CSP) header meta tag
  - Client-side input escaping & sanitization
  - Secure outbound external links (`target="_blank"` and `rel="noopener noreferrer"`)
